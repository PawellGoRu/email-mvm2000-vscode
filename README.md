# HTML-письмо PowerHV

## Структура

```text
powerhv-email-vscode/
├── assets/images/baner600x95_3.jpg  — изображение шапки
├── src/email.html                   — основной шаблон письма
├── .vscode/                         — настройки VS Code
└── README.md                        — эта инструкция
```

## Редактирование

1. Откройте папку `powerhv-email-vscode` в VS Code.
2. В `src/email.html` замените `[Имя Отчество]` на имя получателя.
3. При необходимости отредактируйте текст только между комментариями `Основной текст письма` и `Подпись`.
4. Откройте `src/email.html` в браузере для проверки вида.

## Сборка и отправка

Соберите готовое письмо командой:

```sh
node scripts/build-eml.mjs
```

Скрипт создаёт `dist/powerhv-introduction.eml`. Баннер встраивается внутрь письма как inline MIME-часть с `Content-ID`, поэтому для его показа получателю не нужен внешний URL. Отправляйте именно этот `.eml` через почтовую программу, поддерживающую импорт готовых писем. Не отправляйте отдельно `src/email-responsive.html` и не заменяйте встроенную картинку ссылкой на файловое хранилище.

Стили намеренно находятся внутри `email.html`: это повышает совместимость с Outlook и большинством почтовых клиентов.
