# HTML-письмо PowerHV

_Обновлено: 6 октября 2026 года._

## Структура

```text
powerhv-email-vscode/
├── assets/images/baner600x95_3.jpg  — изображение шапки
├── src/email.html                   — HTML-шаблон для просмотра и редактирования
├── src/email-responsive.html        — адаптивный шаблон для сборки EML
├── scripts/build-eml.mjs            — сборка готового письма
├── .vscode/                         — настройки VS Code
└── README.md                        — эта инструкция
```

## Редактирование

1. Откройте папку `powerhv-email-vscode` в VS Code.
2. В `src/email-responsive.html` замените имя получателя и при необходимости отредактируйте текст: именно этот шаблон используется при сборке EML.
3. `src/email.html` предназначен для локального просмотра; синхронизируйте в нём изменения, если проверяете письмо в браузере.
4. Откройте `src/email.html` в браузере для проверки вида.

## Сборка и отправка

Соберите готовое письмо командой:

```sh
node scripts/build-eml.mjs
```

Скрипт создаёт `dist/powerhv-introduction.eml`. При необходимости путь к файлу можно передать аргументом, например `node scripts/build-eml.mjs /путь/к/письму.eml`. Баннер встраивается внутрь письма как inline MIME-часть с `Content-ID`, поэтому для его показа получателю не нужен внешний URL. Это самодостаточный вариант письма: картинка хранится внутри самого `.eml`, шаблон не зависит от сайта, CDN или файлового хранилища. Отправляйте именно этот `.eml` через почтовую программу, поддерживающую импорт готовых писем. Не отправляйте отдельно `src/email-responsive.html` и не заменяйте встроенную картинку ссылкой на файловое хранилище.

Стили шаблонов находятся внутри HTML: это повышает совместимость с Outlook и большинством почтовых клиентов.
