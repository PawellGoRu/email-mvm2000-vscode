# HTML-письмо PowerHV

_Обновлено: 6 октября 2026 года._

## Структура

```text
powerhv-email-vscode/
├── assets/images/baner600x95_3.jpg  — изображение шапки
├── src/email.html                   — HTML-шаблон для просмотра и редактирования
├── src/email-responsive.html        — адаптивный шаблон для сборки EML
├── scripts/build-eml.mjs            — сборка готового письма
├── .vscode/                         — настройки VS Code
└── README.md                        — эта инструкция
```

## Редактирование

1. Откройте папку `powerhv-email-vscode` в VS Code.
2. В `src/email-responsive.html` замените имя получателя и при необходимости отредактируйте текст: именно этот шаблон используется при сборке EML.
3. `src/email.html` предназначен для локального просмотра; синхронизируйте в нём изменения, если проверяете письмо в браузере.
4. Откройте `src/email.html` в браузере для проверки вида.

## Сборка и отправка

Соберите готовое письмо командой:

```sh
node scripts/build-eml.mjs
```

Скрипт создаёт `dist/powerhv-introduction.eml`. При необходимости путь к файлу можно передать аргументом, например `node scripts/build-eml.mjs /путь/к/письму.eml`. Баннер встраивается внутрь письма как inline MIME-часть с `Content-ID`, поэтому для его показа получателю не нужен внешний URL. Это самодостаточный вариант письма: картинка хранится внутри самого `.eml`, шаблон не зависит от сайта, CDN или файлового хранилища. Отправляйте именно этот `.eml` через почтовую программу, поддерживающую импорт готовых писем. Не отправляйте отдельно `src/email-responsive.html` и не заменяйте встроенную картинку ссылкой на файловое хранилище.

Стили шаблонов находятся внутри HTML: это повышает совместимость с Outlook и большинством почтовых клиентов.

## Шаблон письма в Apple Mail (macOS)

### Способ 1 (рекомендуется): готовый .eml открывать прямо в Mail

Баннер в `dist/powerhv-introduction.eml` встроен как inline-MIME часть (`cid:`), а HTML внутри письма ссылается на неё через `cid:powerhv-banner`. Если открыть такой `.eml` двойным кликом, macOS передаёт его приложению Mail, и письмо отображается полностью и корректно (в отличие от простого HTML-файла, где браузеры и Mail могут обрезывать содержимое).

1. Соберите письмо:

   ```sh
   npm run build-eml
   ```

2. Откройте `dist/powerhv-introduction.eml` двойным кликом в Finder (или командой `open dist/powerhv-introduction.eml`) — оно откроется в Mail в режиме предпросмотра со всем текстом и баннером.

3. Скопируйте содержимое окна предпросмотра (`Cmd+A`, `Cmd+C`) и вставьте (`Cmd+V`) в новое сообщение Mail (`Cmd+N`). Баннер перенесётся как вложение письма — это нормально, у получателя он покажется inline.

4. Заполните тему: **Высоковольтные испытательные и измерительные системы PowerHV**, выберите нужный аккаунт «От кого», сохраните как шаблон (ящик Templates / Файл > Сохранить как шаблон).

### Способ 2 (запасной): копирование из браузера

Если первый способ неудобен, можно copy-paste из браузера. ⚠️ При выделении мышью не захватывайте верхнюю строку `<head>` — выделяйте строго от баннера до подписи; иначе Mail может обрезать часть абзацев.

1. `npm run mail-template` → создаётся `preview/mail-template.html` (полный HTML письма с base64-баннером; обращение с плейсхолдером «Уважаемый [Имя Отчество]!»).

2. Откройте этот файл в Safari (двойной клик в Finder либо `open preview/mail-template.html`).

3. Выделите всё (`Cmd+A`), скопируйте (`Cmd+C`), вставьте (`Cmd+V`) в новое сообщение Mail (`Cmd+N`).

4. Проверьте, что на месте все части письма: обращение, два вводных абзаца, блок про МВМ-2000, абзац про КП, три пункта (референс-листы / во вложении / отзывы) и подпись.

5. Сохраните как шаблон Mail: включите ящик шаблонов (`Mail > Настройки > Создавать новые сообщения на основе шаблонов` / «Файл» > «Сохранить как шаблон…»), либо перетащите черновик в ящик **Templates**. Дальнейшие рассылки: `Файл > Новое сообщение из шаблона`.

6. При необходимости замените «[Имя Отчество]» на имя получателя и укажите адрес в поле «Кому». Для массовой рассылки удобнее генерировать персонализированные `.eml` командой `npm run campaign` (см. `recipients.csv`) — скрипт сам подставит имена из CSV вместо плейсхолдера [Имя Отчество].

Помощник для открытия файла и запуска Mail:

```sh
osascript scripts/build-mail-template.applescript "$(pwd)/preview/mail-template.html"
```

**Ограничение:** при вставке из браузера Mail сохраняет картинку как вложение письма (обычно работает корректно); если у получателя картинки скрыты, используйте вариант с `.eml` из раздела «Сборка и отправка» — там баннер встроен по стандарту MIME `cid:`.
